A lightweight Windows utility that displays your DualSense controller's battery level right in the system tray, so you always know how much charge is left without opening any menus or game overlays.
The app talks to the controller directly over USB HID, reads the battery percentage and charging state, and renders a compact, color-coded icon in the tray. The icon shifts color as the battery drains — green when healthy, yellow as it gets lower, and red when it's time to charge — giving you an at-a-glance status. It also recognizes charging states such as discharging, charging, fully charged, and even controller voltage or temperature warnings reported by the hardware.
The tray reading refreshes automatically every few seconds, and a right-click menu lets you force an immediate refresh or quit the app. A built-in single-instance lock makes sure only one copy runs at a time, so you won't end up with duplicate icons cluttering your tray.
For tinkerers, the app includes an optional ESP32 integration: it can stream the current battery level over a serial connection to an ESP32 microcontroller, making it easy to build your own external battery display, LED indicator, or other hardware companion.
Built in Python using hid for controller communication, pystray and Pillow for the tray icon, and pyserial for the optional ESP32 link.
